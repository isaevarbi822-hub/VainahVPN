The Earth land polygons are Natural Earth 1:110m public-domain data.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
License: https://github.com/nvkelso/natural-earth-vector/blob/master/LICENSE.md

The video renderer uses these polygons to draw a rotating globe. It does not
represent live VPN locations, availability or measurements.
