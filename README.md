# Vainah VPN · Next

Новая архитектура Vainah VPN: **Python API и личный кабинет**, отдельно **нативный клиент с libbox** для Android. Это новая кодовая база, а не копия Netlify-проекта.

> **Статус: foundation / preview.** Web-кабинет работает в деморежиме без персональных данных. **Реального VPN-подключения через браузер и libbox пока нет.** Полную работу туннеля подтверждаем только тестами на устройствах.

## Структура

- `backend/vainah` — FastAPI: health, состояние модулей, диагностика, безопасная проверка VLESS/Reality без хранения ключей.
- `web` — новый адаптивный кабинет, 9 разделов. Нет фиктивных подключений, пинга, платежей и подписок.
- `mobile/android` — контракт нативного движка и план интеграции официального libbox.
- `backend/tests` — тесты API и импорта. `.github/workflows` — CI.
- `docs/ARCHITECTURE.md` — границы сервисов и план реального подключения.

## Запуск локально (Python 3.11+)

```bash
cd backend
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -e ".[dev]"
uvicorn vainah.main:app --reload
```

Откройте http://127.0.0.1:8000, документация API: http://127.0.0.1:8000/docs.

Тесты: `cd backend && python -m pytest -q`.

## Развёртывание

`render.yaml` — Python Web Service (команда запуска `uvicorn vainah.main:app --host 0.0.0.0 --port $PORT`). По умолчанию `VAINAH_MODE=preview`, нет реальных аккаунтов и подписок.

## Безопасность и границы

- H1Cloud не подключён, пока не известен согласованный API и безопасная схема проверки прав. HTTP 403 требует диагностики, а не обхода.
- Clerk — только после реализации серверной проверки токенов. До этого **личные данные не выдаются**.
- RollyPay — отключён. Никаких «оплачено» без проверенного вебхука и состояния в БД.
- Приватные VLESS-ссылки и API-ключи никогда не коммитить в GitHub.
- Python **не заменяет libbox**: libbox — Go-библиотека, которая работает в нативном VPN-сервисе Android/iOS. Python обслуживает веб/API, не создаёт туннель на телефоне.
- Исходный репозиторий `Vainahvpn_bot` остаётся нетронутым.

## Roadmap

1. Поднять preview Python и проверить CI.
2. Подключить Clerk JWT + БД + авторизованные API и H1Cloud-адаптер.
3. Android: VpnService + официальный libbox, защищённое хранилище, проверяемое состояние туннеля.
4. Стабильный импорт HTTPS-подписок с детальной диагностикой 403/timeout, без небезопасных TLS-обходов.
5. После сквозных тестов — платёжный провайдер, десктоп и Apple платформы.
